# WakeyWakey

Ежедневник-будильник для Android: запись → дата и время → в нужный момент приложение напоминает и, если нужно, звонит снова и снова, пока у записи не отмечено «Завершено».

## Режимы напоминания

| Режим | Что происходит |
|---|---|
| Лайтово | Одно уведомление в шторке со звуком уведомления. Не повторяется. |
| Настойчиво | Всплывающее уведомление с вашей мелодией (до 15 с), повтор через заданный интервал, пока не нажмёте «Завершено». Уважает беззвучный режим. |
| Экстрим | Будильник на весь экран поверх блокировки, звонит через поток будильника (беззвучный режим не мешает), повтор через интервал, пока не отметите «Завершено». Можно включить задачку для выключения и принудительную громкость. |

Отдельная вкладка **«Дни рождения»**: дата + чей праздник, напоминание каждый год в выбранное в настройках время, с возрастом и кнопкой «Поздравил». Накануне записи или дня рождения приходит тихое уведомление в шторке.

Режим по умолчанию задаётся в настройках, у каждой записи его можно поменять. Есть «Отложить», повторы (каждый день, по будням, каждую неделю, месяц, год), предупреждение заранее и свои мелодии с телефона.

## Установка

Скачайте `WakeyWakey-x.y.z.apk` из [релизов](https://github.com/erronsivors/WakeyWakey/releases/latest) и откройте на телефоне. Дальше обновления ставятся из самого приложения: **Настройки → Обновления → Проверить обновления**.

После первого запуска откройте **Настройки → Надёжность звонка** и включите всё, что отмечено красным, затем нажмите «Пробный экстрим-будильник». На Xiaomi, Huawei, Honor и Samsung ещё разрешите автозапуск и снимите ограничения фоновой работы.

Нужен Android 8.0 или новее.

## Сборка

Нужны JDK 17 и Android SDK (platform 35).

```bash
./gradlew assembleDebug        # отладочный APK: app/build/outputs/apk/debug/
python release.py 1.1.0        # выпуск новой версии (нужен keystore.properties)
```

`release.py` повышает versionCode, собирает подписанный APK, ставит тег и публикует GitHub-релиз с текстом из `CHANGELOG.md`. Ключ подписи (`keystore.properties`, `keystore/`) в репозиторий не входит. Без него обновление не встанет поверх уже установленного приложения.

## Устройство

- `Model.kt` — запись, режимы, повторы, хранение в JSON.
- `Birthdays.kt`, `BirthdayEditScreen.kt` — дни рождения (ежегодные записи с датой отдельно от времени).
- `Alarms.kt` — расписание через AlarmManager (`setAlarmClock`), действия «Завершено/Отложить», уведомления, ресиверы (включая восстановление после перезагрузки).
- `AlarmService.kt` — служба, которая играет мелодию и вибрирует.
- `AlarmActivity.kt` — экран будильника поверх блокировки.
- `HomeScreen.kt`, `EditScreen.kt`, `SettingsScreen.kt` — интерфейс (Jetpack Compose).
- `Updater.kt` — проверка и установка новых версий из GitHub-релизов.
